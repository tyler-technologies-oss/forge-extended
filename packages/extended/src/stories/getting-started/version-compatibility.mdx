# Version Compatibility

> **Deprecated:** these packages are in a 90-day deprecation period that ends on January 10, 2027. They will receive no new
> features, and they will no longer be maintained after the deprecation period ends. The extended components are included in
> `@tylertech/forge` 3.17.0 and later, with framework wrappers in `@tylertech/forge-angular` and `@tylertech/forge-react`.
> See the [migration guide](?path=/docs/migrating-to-forge-core--docs).
>
> If you have any concerns about this timeline, please let us know in the <a href="https://teams.microsoft.com/l/channel/19%3A1gCw-wLjrS56X_iAY0mpHpk4PyWOi08JiMM7Kc1xvho1%40thread.tacv2/Support?groupId=2bb1b8ea-cd12-4df5-a4ab-0c895bfcda5c&amp;tenantId=7cc5f0f9-ee5b-4106-a62d-1b9f7be46118" target="_blank" rel="noopener noreferrer">Forge Support Teams channel</a>.

| --------------------------- | ------------------ |
| `^1.0.0`                    | `^3.0.0`           |
